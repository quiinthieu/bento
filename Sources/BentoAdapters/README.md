# BentoAdapters

`BentoAdapters` contains per-agent `AgentAdapter` implementations, each driven exclusively by a verified `PathCatalog` for read-only discovery, folder-scoped precedence resolution, context budget contributions, log discovery/decoding, and reversible fix capability metadata:

- **`AdapterPathNormalizer`:** Shared `<HOME>` canonical identity hashing, `BENTO_SYSTEM_ROOT` isolation, and cycle-safe sorted `ReadOnlyFileSystem` traversal.
- **`BuiltInBudgetCatalog` & `AdapterBudgetContributor`:** `fatalError`-free loader for `Resources/builtins/<agent>.json` overhead baselines with provenance (`measuredOn`, `agentVersion`, `sourceNote`) and shared `BudgetContribution` mapping separating pre-prompt vs conditional/deferred/on-invoke items.
- **`AgentAdapters` & `RepoDiscovery`:** Central registry of all six v1 adapters (`AgentAdapters.all`) and read-only multi-source repository discovery (`RepoDiscovery.discover`) across Claude `~/.claude.json` + `-`-encoded project folders, Codex `config.toml` `[projects]` + `session_meta.cwd` logs, Gemini `tmp/<sha256>` project hashes, Copilot `trusted_folders` + `workspace.yaml` / `events.jsonl` logs, shallow `.git` scanning (depth ≤ 3), and user manual/pinned/hidden overrides, deduplicated by `realPath` while ignoring missing directories.
- **`ClaudeCode/` (`ClaudeCodeAdapter`):** Verified Claude Code integration (`Docs/adapters/claude-code.md`) covering managed/projectLocal/project/user settings precedence, `.mcp.json` trust & approval gating (`enabledMcpjsonServers`, `disabledMcpjsonServers`, `enableAllProjectMcpServers`, enterprise `deniedMcpServers`), nested `CLAUDE.md` / `CLAUDE.local.md` concatenation and `@path` imports, `.claude/rules/` `paths:` conditional globs, skills, cached plugins (`installed_plugins.json` + `enabledPlugins`), subagents, slash commands, 3-level lifecycle hooks, and session log discovery.
- **`Codex/` (`CodexAdapter`):** Verified OpenAI Codex CLI integration (`Docs/adapters/codex.md`) covering `/etc/codex/{requirements.toml,config.toml}`, `$CODEX_HOME/config.toml`, and project/directory `.codex/config.toml` with `[projects."<path>"].trust_level` gating, `[profiles.<name>]` overrides, `[mcp_servers.*]` (`enabled_tools`, `disabled_tools`, `env_vars`, `bearer_token_env_var`), `AGENTS.override.md` / `AGENTS.md` / `project_doc_fallback_filenames` instruction chains with `project_doc_max_bytes` truncation, `.agents/skills` vs `.codex/skills` + `.system` built-in skills, `hooks.json` + `[hooks].notify`, and `.jsonl` / `.jsonl.zst` rollout log discovery.
- **`Gemini/` (`GeminiAdapter`):** Verified Google Gemini CLI integration (`Docs/adapters/gemini.md`) covering 4-tier settings merge (`system-defaults.json` → `~/.gemini/settings.json` → `<repo>/.gemini/settings.json` → `/Library/Application Support/GeminiCli/settings.json`), `context.fileName` hierarchy + `@import` expansion + JIT descendant `GEMINI.md` files, `mcpServers` (`httpUrl`, `url`, `command`, `includeTools`, `excludeTools`, `mcp.excluded`, `mcp.allowed`), `.agents/skills` vs `.gemini/skills`, Markdown subagents, namespaced TOML custom commands (`commands/**/*.toml`), `~/.gemini/extensions/*` (`extension-enablement.json` + bundled MCP/context/skills/agents/commands/hooks), `.geminiignore`, and `tmp/*/chats/session-*` transcript discovery.
- **`Copilot/` (`CopilotAdapter`):** Verified GitHub Copilot CLI integration (`Docs/adapters/copilot.md`) covering `~/.copilot/{config.json,settings.json,copilot-instructions.md,mcp-config.json}`, `.github/copilot-instructions.md`, modular `.github/instructions/**/*.instructions.md` (`applyTo` → `LoadMode.conditional`), `AGENTS.md` hierarchy, `.github/mcp.json` > `.vscode/mcp.json` (`servers` / `mcpServers`) > `~/.copilot/mcp-config.json` MCP precedence (`tools: ["*"]` vs explicit tool allowlists), `~/.agents/skills` / `~/.copilot/skills` / `.github/skills`, `.agent.md` custom agents, `.prompt.md` commands, lifecycle hooks, and `session-state/<id>/{events.jsonl,workspace.yaml}` log discovery.
- **`Cursor/` (`CursorAdapter`):** Scoped inventory and resolution integration (`Docs/adapters/cursor.md`, capabilities `[.inventory, .resolution]`) covering `.cursor/rules/**/*.{mdc,md}` activation modes (`alwaysApply`, `globs`, `description`), legacy `.cursorrules`, `AGENTS.md` hierarchy, `<repo>/.cursor/mcp.json` > `~/.cursor/mcp.json` precedence, skills, subagents, `.cursorignore`, and `.cursorindexingignore`.
- **`Windsurf/` (`WindsurfAdapter`):** Scoped inventory and resolution integration (`Docs/adapters/windsurf.md`, capabilities `[.inventory, .resolution]`) covering macOS enterprise rules (`/Library/Application Support/Windsurf/rules`), `~/.codeium/windsurf/memories/global_rules.md` (`6,000`-char cap), `.windsurf/rules/**/*.md` (`12,000`-char cap and `trigger: always_on | glob | model_decision | manual` modes), legacy `.windsurfrules`, `AGENTS.md` hierarchy, `~/.codeium/windsurf/mcp_config.json` (`serverUrl` / `disabledTools`), global & workspace workflows, and `.codeiumignore`.
