# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

- **T13 Hygiene engine:** Added deterministic 23-rule opposing-directive pattern catalog in `Resources/hygiene/conflicts.yaml` (synchronized byte-for-byte with bundled `BentoHygiene` resources via `ConflictCatalog`); implemented `MinHashLSH` (5-gram word shingles, deterministic 128-permutation SplitMix64 signatures, 32×4 LSH bands, and exact shingle Jaccard `>= 0.80`), modality- and language-scope-aware `ConflictDetector` (emitting both opposing spans), and `HygieneEngine` in `BentoHygiene` (physical `realPath` deduplication, frontmatter-adjusted 1-based line spans, pure `@import` directive skipping, exact/near-duplicate rule detection, identical non-symlinked skill consolidation suggestions, `>= 70%` block-level `@AGENTS.md` import suggestions gated by `FixSupport`, Windsurf 6k/12k char caps, Codex `project_doc_max_bytes` truncation, configurable always-on rule token limits, broken `@import`s, and invalid JSON/TOML/YAML config findings); added `bentoctx hygiene [--repo PATH] [--agent A] [--fail-on warning|error] [--max-rule-tokens N] [--json]` and `Docs/cli-schema.md` specification; and added `Fixtures/homes/clean/` (0 false positives) plus `polyglot-findings.json` golden and `windsurf-limits` / read-only tests.
- **T12 Usage join + calibration:** Added `CalibrationSample` / `CalibrationRecord`, `ArtifactUsageJoin` / `UsageJoinReport`, and Keychain-backed `APIKeyProviding` (`KeychainAPIKeyStore`, `InMemoryAPIKeyStore`) in `BentoCore`; added privacy-safe `firstUserMessageCharCount` tracking in `ClaudeCodeLogDecoder`, `GeminiLogDecoder`, `LogIngestor`, and `BentoStore` migration `v3_session_user_chars_and_finding_fixes`; implemented `UsageJoinEngine` (`"cost × unused"` ranking, canonical `mcp__<server>__<tool>` / skill / subagent / command matching, and `Finding.Kind.unused` emission with `>= 5` minimum-session guard and 30-day default lookback) in `BentoLogIngest`; added least-squares `CalibrationFitter` (recovering synthetic `k = 1.12` within `±0.02`) and opt-in content-hash-cached `AnthropicCountTokens` (`POST /v1/messages/count_tokens`) + `GeminiCountTokens` (`models/{model}:countTokens`) in `BentoTokenizer`; added `calibration`, `measuredFirstTurnMedianInput`, and `finding` (`dismissed`-preserving) persistence in `BentoStore`; wired `measuredFirstTurnInput`, calibration fitting, `--api anthropic|gemini`, `--min-sessions`, `artifactUsage`, and `unusedFindings` into `Workspace` / `bentoctx budget` / `bentoctx usage` and `Docs/cli-schema.md`; and added `Fixtures/homes/usage-join/`.
- **T11 LogIngest core + decoders:** Vendored BSD-3-Clause `facebook/zstd` v1.5.7 decompression C sources as `CZstd`, added 64 KB zero-copy `StreamingLineReader` (holding partial trailing lines uncommitted and skipping `>16 MB` lines with diagnostics), `ZstdLineReader` (`ZSTD_decompressStream` with non-crashing corrupt/truncated `.zst` diagnostics), and parallel `LogIngestor` (resumable `offset_consumed` + `decoder_state`, inode/shrink rotation re-read with deterministic SHA-256 event deduplication, and compressed `(size, mtime, inode)` immutability skipping) in `BentoLogIngest`; added `FastLogJSON` UTF-8 pre-filtering and Howard Hinnant ISO-8601 parsing in `BentoParsing`; implemented privacy-safe streaming decoders for Claude Code (`message.id`/`requestId`/`tool_use.id` chunk deduplication), Codex CLI (>210 MB/s Debug plain JSONL throughput), Gemini CLI (modern `.jsonl` + legacy `.json` + `<project-hash>` `inferredCwd`), and Copilot CLI; added `BentoStore+LogIngest` (`usage_event`, `session`, `log_file`, `usageSummary`) and `bentoctx ingest` / `bentoctx usage` documented in `Docs/cli-schema.md` and `Docs/adapters/*.md`.
- **T10 MCP probe:** Added `Fixtures/mcp/fake-server/server.py` (`normal`, `paginate`, `sleep`, `crash`, and `dump-env` modes), `MCPToolSchema` / `MCPServerConfigHasher` / `MCPProbeRecord` / `MCPFallbackEstimate` / `MCPProbeCaching` / `MCPConsentPersisting` in `BentoCore`, config-hash-gated `MCPConsentStore` + `StdioMCPClient` (scrubbed `PATH`/`HOME`/declared-`envKeys` environment, `cwd=repo`, no TTY, 16 KB stderr cap, 5 s handshake + 10 s `tools/list` timeout ceiling with `SIGTERM`/`SIGKILL` reap, and `nextCursor` pagination) + `StreamableHTTPMCPClient` (JSON + SSE `text/event-stream`, `Mcp-Session-Id`, `401`/`403` OAuth skip) + `MCPProber` in `BentoMCPProbe`, `mcp_probe_cache` and `setting`-backed consent persistence in `BentoStore`, ephemeral raw declared-env resolution (`MCPEnvironmentResolver`), probed tool-schema tokenization, median fallback estimates, and Claude Code `ENABLE_TOOL_SEARCH` (`true`/`false`/`auto`/`auto:N`) threshold deferral in `BudgetEngine` / `Workspace`, and `bentoctx budget --probe-mcp <server>` documented in `Docs/cli-schema.md` and `Docs/adapters/claude-code.md`.
