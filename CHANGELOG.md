# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

- **T07 Store + Scanner + FSEvents:** Added `GRDB.swift` v7 migrations for all 12 §4.2 SQLite tables and indexes in `BentoStore` (WAL-mode `DatabasePool`, lossless multi-snapshot persistence, repo pinning, typed settings, 180-day usage-event retention pruning, `VACUUM`, and `deleteAllData`), `Snapshot` / `ScanScope` / `SnapshotDelta` / `SnapshotPersisting` in `BentoCore`, `Workspace` actor + `PathCatalogMatcher` + dual-stream `FSEventsFileWatcher` (with read-only polling fallback and `ManualFileWatcher`) in `BentoScanner`, and hermetic `scan` / `inventory` / `resolve` `--json` subcommands in `BentoCLI` documented in `Docs/cli-schema.md`.
- **T06 Copilot, Cursor, Windsurf adapters + repo discovery:** Verified official GitHub Copilot CLI, Cursor, and Windsurf Cascade paths, limits, and precedence rules in `Docs/adapters/{copilot,cursor,windsurf}.md`; implemented `CopilotAdapter` (`applyTo` conditional instructions, `.github`/`.vscode`/user MCP precedence, skills, `.agent.md` custom agents, `.prompt.md` commands, hooks, and `session-state` logs), scoped `CursorAdapter` and `WindsurfAdapter` (`6,000`-char global and `12,000`-char workspace caps + `trigger` modes), `AgentAdapters` registry, and §5.3 `RepoDiscovery` (`realPath` deduplication, missing-directory filtering, Claude `-`-encoded project decoding, Gemini SHA-256 project-hash matching, shallow `.git` scanning, and pin/hide options); added `copilot-basic/`, `cursor-basic/`, and `windsurf-limits/` fixture homes with contract tests and goldens.
- **T05 Codex + Gemini adapters:** Verified official OpenAI Codex CLI and Google Gemini CLI paths and precedence rules in `Docs/adapters/codex.md` and `Docs/adapters/gemini.md`, implemented `CodexAdapter` (`CodexPathCatalog`, `CodexDiscovery`, `CodexPayloadParser`, `CodexResolver`, `CodexLogDecoder`) and `GeminiAdapter` (`GeminiPathCatalog`, `GeminiDiscovery`, `GeminiPayloadParser`, `GeminiResolver`, `GeminiLogDecoder`), and added `codex-basic/` (including `.jsonl.zst` rollout logs) and `gemini-basic/` fixture homes with contract tests and inventory/resolution goldens.
- **T04 Claude Code adapter:** Verified official Claude Code paths and precedence rules in `Docs/adapters/claude-code.md`, implemented `ClaudeCodeAdapter` (`ClaudeCodePathCatalog`, `ClaudeCodeDiscovery`, `ClaudeCodePayloadParser`, `ClaudeCodeResolver`, `AdapterPathNormalizer`), added shared `AdapterContractSuite` and `RecordingReadOnlyFileSystem` in `BentoTestSupport`, and added `claude-basic/`, `claude-plugins/`, and `claude-precedence/` fixture homes with inventory and resolution goldens.
- **T03 Parsing module:** Added ADR `Docs/decisions/001-toml-library.md` selecting `dduan/TOMLDecoder` alongside `jpsim/Yams`, implemented tolerant `JSONCParser` (`//`, `/* */`, trailing commas, depth guard), `TOMLParser`, `FrontmatterParser` + `MDCParser` (including unquoted leading-`*` glob recovery), `MarkdownRuleSplitter`, recursive `ImportResolver` (Claude/Gemini `@import` syntax, cycle detection, max-depth enforcement, code-block exclusion), parse-time `SecretRedactor`, and `Fixtures/homes/hostile/` adversarial tests.
- **T02 Core models + ReadOnlyFileSystem + fixture harness:** Implemented all §4.1 domain models and §5.1 adapter/environment protocols in `BentoCore`, collision-resistant SHA-256 `ArtifactID` and `ContentHasher`, POSIX `lstat`-backed `LocalReadOnlyFileSystem`, `FixtureHome` and `GoldenFile` test harness (`RECORD_GOLDEN=1` + `<HOME>` path normalization), and `empty/` + `polyglot/` skeleton fixtures.
- **T01 Package & tooling skeleton:** Added `Package.swift` across all §3.1 targets with Swift 6 strict concurrency, `Product` constants synchronized with `Config/Product.xcconfig`, XcodeGen `Project.yml`, `swift-format` configuration, `Scripts/lint-writes.sh` (+ self-test `Scripts/test-lint-writes.sh`), GitHub Actions `ci.yml`, and `DependencyGraphTests` / `ProductTests` / `LintWritesTests` / `RootWindowTests`.
